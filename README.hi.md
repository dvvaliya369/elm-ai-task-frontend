# ELM AI कार्य फ्रंटएंड

एक आधुनिक सोशल मीडिया एप्लिकेशन जो React, TypeScript, और Material-UI के साथ बनाया गया है। यह एप्लिकेशन उपयोगकर्ताओं को खाते बनाने, छवियों/वीडियो के साथ पोस्ट साझा करने, लाइक्स और कमेंट्स के माध्यम से सामग्री के साथ बातचीत करने, और अपनी व्यक्तिगत पोस्ट प्रबंधित करने की अनुमति देता है।

## 🚀 सुविधाएँ

- **उपयोगकर्ता प्रमाणीकरण**: JWT टोकन प्रबंधन के साथ लॉगिन/साइनअप
- **पोस्ट प्रबंधन**: मीडिया समर्थन के साथ पोस्ट बनाना, संपादित करना, हटाना
- **सामाजिक बातचीत**: पोस्ट पर लाइक और कमेंट करना
- **व्यक्तिगत डैशबोर्ड**: ग्रिड लेआउट में अपनी पोस्ट देखना
- **प्रतिक्रियाशील डिज़ाइन**: Material-UI के साथ मोबाइल-फर्स्ट दृष्टिकोण
- **रियल-टाइम अपडेट**: बेहतर UX के लिए आशावादी UI अपडेट
- **संरक्षित मार्ग**: प्रमाणीकरण गार्ड के साथ सुरक्षित नेविगेशन

## 🛠️ टेक स्टैक

- **फ्रंटएंड फ्रेमवर्क**: React 19.1.1
- **भाषा**: TypeScript
- **बिल्ड टूल**: Vite 7.1.2
- **UI लाइब्रेरी**: Material-UI (MUI) 7.3.1
- **स्टेट मैनेजमेंट**: Redux Toolkit 2.8.2
- **रूटिंग**: React Router DOM 7.8.1
- **HTTP क्लाइंट**: Axios 1.11.0
- **स्टाइलिंग**: Emotion (CSS-in-JS)
- **आइकॉन्स**: Material-UI Icons
- **फॉंट्स**: Roboto (Google Fonts)

## 🚦 शुरू करना

### पूर्वापेक्षाएँ

- Node.js (v18 या उच्चतर)
- npm या yarn पैकेज मैनेजर

### इंस्टॉलेशन

1. रिपॉजिटरी को क्लोन करें:
```bash
git clone git@github.com:dvvaliya369/elm-ai-task-frontend.git
cd elm-ai-task-frontend
```

2. निर्भरताएँ इंस्टॉल करें:
```bash
yarn install
```

3. विकास सर्वर शुरू करें:
```bash
yarn dev
```

4. अपने ब्राउज़र खोलें और `http://localhost:5173` पर नेविगेट करें

### उपलब्ध स्क्रिप्ट

- `yarn run dev` - विकास सर्वर शुरू करें
- `yarn run build` - उत्पादन के लिए बिल्ड करें
- `yarn run preview` - उत्पादन बिल्ड का पूर्वावलोकन करें
- `yarn run lint` - ESLint चलाएँ

## 🔗 API एकीकरण

एप्लिकेशन `http://localhost:8000/api` पर चल रहे बैकएंड API के साथ एकीकृत होता है। प्रमुख एंडपॉइंट्स में शामिल हैं:

- **प्रमाणीकरण**: `/auth/login`, `/auth/signup`, `/auth/refresh`
- **पोस्ट**: `/post/list`, `/post/create`, `/post/update`, `/post/delete`
- **उपयोगकर्ता पोस्ट**: `/post/user/:userId`
- **बातचीत**: `/post/like/:postId`, `/post/comment/:postId`
- **प्रोफाइल**: `/profile`, `/profile/update`

## 🎨 UI/UX सुविधाएँ

- **प्रतिक्रियाशील ग्रिड लेआउट**: मोबाइल पर 2 आइटम, डेस्कटॉप पर 3
- **होवर इफेक्ट**: लाइक/कमेंट काउंट के साथ इंटरएक्टिव पोस्ट पूर्वावलोकन
- **लोडिंग स्टेट**: स्केलेटन लोडर और स्पिनर
- **टोस्ट अधिसूचनाएँ**: सफलता/त्रुटि प्रतिक्रिया
- **खाली स्टेट**: कोई सामग्री न होने पर सहायक संदेश
- **संरक्षित नेविगेशन**: प्रमाणीकृत उपयोगकर्ताओं के लिए मार्ग गार्ड

## 🔧 प्रमुख घटक

### MyPosts घटक
- उपयोगकर्ता की व्यक्तिगत पोस्ट का ग्रिड व्यू
- होवर ओवरले के साथ प्रतिक्रियाशील लेआउट
- React.memo और useCallback के साथ प्रदर्शन अनुकूलित

### PostCard घटक
- मीडिया समर्थन के साथ पोस्ट सामग्री प्रदर्शित करता है
- लाइक/कमेंट बातचीत
- पोस्ट मालिकों के लिए तीन-डॉट मेनू

### Navbar घटक
- प्रोफाइल ड्रॉपडाउन के साथ प्रतिक्रियाशील नेविगेशन
- मोबाइल-फ्रेंडली हैमबर्गर मेनू
- प्रमाणीकरण स्टेट जागरूकता

## 📱 प्रतिक्रियाशील डिज़ाइन

- **मोबाइल (xs)**: पंक्ति में 2 पोस्ट, कॉम्पैक्ट नेविगेशन
- **टैबलेट (sm)**: पंक्ति में 2 पोस्ट, विस्तारित नेविगेशन
- **डेस्कटॉप (md+)**: पंक्ति में 3 पोस्ट, पूर्ण नेविगेशन

## 🔒 प्रमाणीकरण प्रवाह

1. उपयोगकर्ता लॉग इन/साइन अप करता है
2. JWT टोकन localStorage में संग्रहीत किए जाते हैं
3. समाप्ति पर स्वत: टोकन रिफ्रेश
4. यदि अप्रमाणीकृत है तो संरक्षित मार्ग लॉगिन पर रीडायरेक्ट करते हैं
5. यदि प्रमाणीकृत है तो सार्वजनिक मार्ग होम पर रीडायरेक्ट करते हैं

## 🚀 प्रदर्शन अनुकूलन

- घटक मेमोइजेशन के लिए React.memo
- स्थिर फ़ंक्शन संदर्भों के लिए useCallback
- मार्ग घटकों के लिए लेजी लोडिंग
- आशावादी UI अपडेट
